# Roadmap

Planned work, grouped by the release it's aimed at. Day-to-day tracking lives
in the GitHub Project; this file is the big picture. Items move into
CHANGELOG.md when they ship.

## 0.10.0: Characters
The heart of the app: players create characters and use their sheets at the table.

- Character creation (name, species, notes) for players and GM NPCs
- Character sheet: main stats with skills grouped underneath, icons, roll
  buttons (D6 and D20), points balance
- Spending points from the sheet (upgrade buttons showing the cost)
- Direct editing on the sheet when the GM allows it
- Highlight improved and recently changed stats
- Choosing abilities for a character

## 0.11.0: Spells and inventory
- GM manages the game's spells; players learn spells for their characters
- Inventory: items with quantities on each character
- Dice roll results posted to the activity feed (optional per game)

## 0.12.0: Table polish
- GM title per game ("The Narrator", "Dungeon Master") used in the activity feed
- Option for the party to see each other's character sheets
- Uploaded avatar images on profiles

## 1.0.0: Campaign-ready
- Everything above, tested through a real session
- Custom SMTP set up so all players receive emails
- Documentation for players and GMs

## Ideas (not yet scheduled)
- D6 Wild Die (explodes on 6, complication on 1)
- D20 ability scores that convert to modifiers (D&D style)
- Stepped upgrade costs (different rates for 1D–3D, 4D–6D, …)
- Session log: date, attendance and summary per session
